# APZ Wallet — Android Client

نسخهٔ رسمی اندروید کیف‌پول APZ Wallet  
ساخته‌شده با **Kotlin + Jetpack Compose**

---

## ✨ ویژگی‌ها
- تولید آدرس APZ روی دستگاه
- ذخیره امن کلیدها
- امضای تراکنش‌ها
- ارتباط با RPC
- UI نئونی و سبک
- سازگار با Android 7 تا 14

---
